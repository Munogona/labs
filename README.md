# Java OOP Labs 1–10

## Requirements

JDK 17+ (JDK 21 recommended). Open the folder in VS Code with the Extension Pack for Java.

## Run

Each lab has its own independent `Main.java` and `run-output.txt`. In a terminal:

```bash
cd Lab01
javac Main.java
java Main
```

Repeat for Lab02–Lab10. Lab07 reads two integers using `Scanner`; press Enter twice for the sample 10 and 2 values or type your own values. Lab10 uses five sample lines by default; run `java Main --interactive` to enter five lines yourself. Lab10 writes `learners.csv` if absent, plus a local `output/` folder with report files.

### Folder guide

- Lab01: Classes and objects
- Lab02: Constructors, this, static
- Lab03: Encapsulation
- Lab04: Inheritance
- Lab05: Polymorphism
- Lab06: Abstract classes and interfaces
- Lab07: Exception handling
- Lab08: Generics and collections
- Lab09: Nested types, enums, records
- Lab10: File I/O, lambdas, streams
